## Description
Fancier Trees is a mod that Replaces naturally generated and grown trees with handcrafted ones.

## Requirement and Compat
This mod Requires [Oh The Trees You'll Grow](https://modrinth.com/mod/oh-the-trees-youll-grow)

This mod has compatibility and custom trees made for:
- [Vanilla Backport](https://modrinth.com/mod/vanillabackport)
- [Biomes o' Plenty](https://modrinth.com/mod/biomes-o-plenty)
